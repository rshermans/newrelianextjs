# Documentação Científica — RELIA Platform

Este diretório contém a documentação científica do projeto RELIA, desenvolvido no âmbito do doutoramento em Ciências da Linguagem / Humanidades Digitais (CEHUM / Universidade do Minho).

## Estrutura

| Ficheiro | Descrição |
|----------|-----------|
| [`protocolo-experimental.md`](protocolo-experimental.md) | Método de experimentação e protocolo de recolha de dados |
| [`hipoteses.md`](hipoteses.md) | Hipóteses de investigação |
| [`metricas.md`](metricas.md) | Métricas de avaliação (aprendizagem, usabilidade, engagement) |
| [`decisoes/`](decisoes/) | Log de decisões de design com justificação pedagógica |
| [`resultados/`](resultados/) | Resultados de experimentação (quando disponíveis) |

## Princípios

1. **Implementação documentada**: cada decisão de design tem justificação pedagógica e referência bibliográfica.
2. **Método de experimentação pensado**: o protocolo experimental é definido antes da implementação.
3. **Métricas alinhadas**: as métricas de avaliação estão alinhadas com as hipóteses de investigação.
4. **Reprodutibilidade**: todo o código e dados são versionados; os resultados são reprodutíveis.
