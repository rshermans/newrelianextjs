# Decisões de Design

Este diretório contém o log de decisões de design do RELIA Platform, cada uma com justificação pedagógica e/ou técnica.

## Formato

Cada decisão é um ficheiro Markdown com:

```markdown
# DD-NNN: Título da Decisão

**Data:** YYYY-MM-DD
**Estado:** aceite | proposta | rejeitada
**Contexto:** Descrição do problema ou necessidade
**Decisão:** O que foi decidido
**Justificação:** Porquê (pedagógica, técnica, científica)
**Consequências:** Impacto na implementação e na investigação
**Referências:** Bibliografia relevante
```
